# Telecom-analysis
##Objetivo
Análisis de información de un empresa de telecomunicaciones para determinar cómo los clientes usan realmente los servicios móviles (llamadas y mensajes).

##Datasets utilizados 
*plans.csv*, *usage.csv*, *users_latam.csv*

##Etapas del análisis 
1. Cargar y explorar la información de los datasets.
2. Identificación de problemas de calidad con los datos (valores nulos, sentinnels y fechas fuera de rango).
3. Limpieza básica reemplazando sentinels, convirtiendo fechas, imputar o marcar NA según las reglas.
4. Resumen estadístico revisando las medidas clave en variables categóricas y numéricas.
5. Visualización & outliers utilizando histogramas y boxplots.
6. Segmentación de datos basados en reglas claras y visualización de proporciones con countplots.
7.  Insight ejecutivo. Redacción de conclusiones y recomendaciones comerciales basadas en los pasos anteriores.

##Para ejecutar el notebook 
*Google Colab*.

##Cómo reproducir el análisis
1. Abre
2. Ejecuta las celdas en orden
3. El notebook carga automáticamente el dataset desde `/data/`
